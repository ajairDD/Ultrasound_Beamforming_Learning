共 **260 页、210 张 PNG 配图**，另有正文中的中文矢量流程图与字符示意。其中，第 5–8 章共 **76 页、83 张配图**（25 张 AI 概念图、58 张 MATLAB 图）。图内标题、图例、坐标名称与说明使用中文，保留业内术语、数学符号、代码标识和单位；MATLAB 图保留原始数值、坐标范围与色标。

PDF 内嵌中文字体，正文支持搜索和复制。第 0–8 章全部采用 A4 纵向页；第 5–8 章的宽幅图随正文流动并按页宽缩放，多列表格可跨页并重复表头，目录列出二级标题，第 6 章两张密集的竖向多子图也统一为 A4 纵向页。打印时可按纸张大小缩放。

每份 PDF 的封面和每一页页脚都包含项目 GitHub 地址、版权与许可摘要；地址可点击，PDF 元数据也写入项目来源、章节 ID 和发布版本。这样即使文件被单独转发，读者仍能回到原始仓库核对版本、引用和最新内容。

源章节仍位于 [`chapters/`](../../chapters/)。中文标签映射、AI 编辑提示词、构建脚本与复现步骤见 [`tools/pdf/README.md`](../../tools/pdf/README.md)。

文件校验值、页数、配图数量与内部链接检查记录见 [`manifest.json`](manifest.json)。
